### 👋 About

I'm a developer who enjoys both low-level systems work and polished web products. I mostly write **Rust** for secure execution and tooling, and **TypeScript / Next.js** for apps.

### 🚀 Projects

- ⚔️ **[IronJudge](https://github.com/pankajyadav-dev/ironjudge)**: sandboxed code execution engine in Rust (Linux namespaces, cgroups v2, seccomp).
- 🏁 **[xForces](https://github.com/pankajyadav-dev/xforces)**: Codeforces-style competitive programming platform (Next.js, Prisma, Bun).
- 🖼️ **[Chitra](https://github.com/pankajyadav-dev/chitra)**: context optimization CLI that indexes codebases with tree-sitter (Rust).
